## Goal
The backend stops sorting the two complete lists of the bookshelves
feature: the reader's bookshelves and a bookshelf's members come in
whatever order the repositories answer, as D11 now says, and the screens of
T079 and T082 sort them. What T074 and T076 built for the order leaves with
it, and the one rule left that folds case and accents, S3's taken name,
keeps its folding private to `BookshelfName`, proven by its own tests.

## Risks and decisions
**Fit.** One run: two use cases lose a sort, an enum loses a field, a file
goes back into its one user, six test cases leave and three guards come;
some ten files, no web, no migration. Rejected: a split (each part is a
few lines, and the folding's move needs both sorts gone first).

**The removals are steps without a red.** Dropping an order adds no
behaviour a test could ask for first: the only red would be a case
asserting some order, which D11 now refuses to promise. Each removal is its
own commit, proven by the cases that remain and the scenarios, unedited,
as T064 deleted a field. Rejected: a case "in the repository's order" (a
promise D11 refuses); one commit for all removals (a reader could not see
which proof holds which removal).

**Three guards on `BookshelfName.isSameAs`, before the order cases leave.**
The order cases of `ListReaderBookshelvesTest` were the only proof that the
folding reads `œ` and `æ` as `oe` and `ae` and keeps spaces; that folding
stays, as S3's taken name, so its proof moves to the rule that still uses
it. Rejected: dropping the `œ`/`æ` spellings (a change to which names S3
calls taken, T075's decision, no spec asking it); leaving them unproven
(production code no test holds); a test file of the folding (private, its
one user tests it).

**`BookshelfName.ignoringCaseAndAccents` leaves.** Its one user was
`ListReaderBookshelves`' sort; a public comparator nothing calls is code no
test motivates. Rejected: keeping it for a later sort (D11 forbids the
backend such a sort).

**`ListReaderBookshelves` keeps `invoke(reader: Reader)`.** It now reads
only `reader.id`, but narrowing it to a `ReaderId` changes the controller
and the stubs of `ApiContractTest` for no rule of this task. Rejected:
`invoke(readerId)` (a web change outside the line, proposable in
`agent/PROPOSED.md`).
