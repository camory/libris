# T053 — The add keeps the chosen source

**Backlog line:**
> - [ ] T053 Backend: the add keeps the chosen source.
>       An edition the add creates keeps its `coverSource` when the name is a
>       source's, `inventaire.io`, `Open Library` or `BnF`, none otherwise,
>       `Libris` included; on an ISBN the house holds the field is ignored.
>       One migration gives `edition` the source, as text (D11, D12).
>       `ApiContractTest`'s keyed `201_ADD_ONE_PIECE_1` sends `inventaire.io`,
>       so its stub carries the source; tests of the request, the use case and
>       the JDBC slice (D07). Realises S3's first *Then* on the backend;
>       un-skips nothing.

**Serves:** spec `covers` S3 (first *Then*: "the edition exists with the
source of the cover shown"; "a card showing the stand-in adds the edition
with no source"), S12's "no chosen source" for the editions already stored,
its Contract section (`NewBook.coverSource`); PRD §3, §4.1; decisions D02,
D04, D07, D10, D11, D12
**First of its kind:** the first migration that adds a column to a table
already holding production rows (`edition`): the rows stored before it take
`NULL`, which S12 reads as "no chosen source".

## Goal
The add keeps the source of the cover the card showed on the edition it
creates, and the database stores it. The worker of T066 and the cascade of
T057 read it to know which source to ask, or that none was chosen.

## Rules in play
- D02 — `CoverSource` stays in `bibliography.domain.lookup`; the aggregate
  `Edition` of `bibliography.domain.edition` holds it; `NewBook` of
  `library.application` carries it (library → bibliography only)
- D04 — the pin stays `v0.8.2`; no contract edit; the add's two keyed cases,
  `201_ADD_ONE_PIECE_1` and `404_NOT_MY_BOOKSHELF`, both send
  `coverSource: inventaire.io`
- D07 — no scenario test is un-skipped or edited; *S3 The add carries the
  cover's source* stays `@Disabled` until T066; the request, the use case
  and the JDBC slice prove the field; the slice starts from a schema cleaned
  and migrated by Flyway, so it migrates `V006`
- D10 — the request field and the domain field are both `coverSource`, the
  contract's word; `AddBookToBookshelf` keeps `operator fun invoke` alone;
  no visibility widened; SQL keywords upper case, identifiers snake_case
- D11 — the source is stored as text, the enum's name in UPPER_SNAKE
  (`INVENTAIRE`, `OPEN_LIBRARY`, `BNF`), no PostgreSQL enum, no `CHECK`,
  read back through `CoverSource.valueOf`; the migration is
  `V006__edition_cover_source.sql`, never edited once merged
- D12 — the name the request carries becomes a `CoverSource` through a
  factory `CoverSource.of(label)` on the companion that answers `null` for
  a name no source bears; the caller, the request's `validate()`, decides
  that `null` means "no source", never a refusal; the use case takes the
  value, never the text; the aggregate takes its source as a constructor
  parameter, a row read back passing its own

## Test plan
One step is one case is one commit; `./gradlew detekt` before each commit;
a step is committed before its guard's mutation is checked. A step marked
red that is green on arrival becomes a guard: its commit body names the
mutation that reds it, checked and reverted, and the PR body lists it.

1. **red then green — each source by its name.** `CoverSourceTest` (new,
   `bibliography.domain.lookup`): every entry of `CoverSource`, looked up by
   its `label` through `CoverSource.of`, answers itself. Creates the
   companion's `of(label: String): CoverSource?`.
2. **red then green — a name no source bears.** `CoverSourceTest`:
   `CoverSource.of("Libris")` is `null`. If step 1's code already answers
   `null`, this step is a guard: mutation, `first` in place of
   `firstOrNull` (it throws `NoSuchElementException`).
3. **red then green — the request names a source.** `NewBookRequestTest`:
   the request helper gains `coverSource` (default `null`); with
   `"inventaire.io"`, `validate()` answers `Accepted` with a book whose
   `coverSource` is `INVENTAIRE`. Creates `NewBookRequest.coverSource:
   String?` and `NewBook.coverSource: CoverSource?`, last parameter of the
   constructor and of `NewBook.of`, no default; `NewBookTest` and
   `AddBookToBookshelfTest` build `NewBook` with `coverSource = null`.
   `ApiContractTest`'s `NEW_ONE_PIECE_1` gains `coverSource = INVENTAIRE`
   in the same commit: run `./gradlew test --tests ApiContractTest` once
   without it and see `201_ADD_ONE_PIECE_1` and `404_NOT_MY_BOOKSHELF` red
   (the stub on exact arguments no longer matches), then with it, green.
4. **guard — a name no source bears is no source, not a refusal.**
   `NewBookRequestTest`: with `"Libris"`, `validate()` answers `Accepted`
   with a book whose `coverSource` is `null`. Mutation: add a
   `ValidationErrorResponse("coverSource", …)` when `coverSource` is set
   and `CoverSource.of` answers `null`.
5. **red then green — the new edition keeps the source.**
   `AddBookToBookshelfTest`: `onePieceTomeOne()` gains `coverSource`
   (`INVENTAIRE` by default in the helper), and *the house lacking the ISBN
   gains the edition and the copy* expects the stored `Edition` with
   `coverSource = INVENTAIRE`. Creates `Edition.coverSource: CoverSource?`,
   after `coverUrl`, no default; every `Edition(...)` of the tree passes
   it (`null`, save this case), and `JdbcEditionRepository` reads it as
   `null` until step 7.
6. **guard — the held edition keeps its own.** `AddBookToBookshelfTest`
   *an ISBN the house holds reaches the existing edition*: Léa adds with
   `INVENTAIRE`, Juliette with `OPEN_LIBRARY`; the single stored edition's
   `coverSource` is `INVENTAIRE`. Mutation: insert the held edition again,
   `heldEdition.copy(coverSource = book.coverSource)`, instead of reaching
   it.
7. **red then green — the source is stored.** `JdbcEditionRepositoryTest`:
   `onePieceTomeOne()` gains `coverSource = INVENTAIRE`; *an inserted
   edition is read back whole by its ISBN-13* reds (read back `null`).
   Creates `V006__edition_cover_source.sql`
   (`ALTER TABLE edition ADD COLUMN cover_source text;`), and the column
   in `INSERT_EDITION` and `SELECT_EDITIONS`, written as the enum's `name`
   and read through `CoverSource.valueOf`.
8. **guard — no source is stored as none.** `JdbcEditionRepositoryTest`:
   `bare()` gains `coverSource = null`; *an edition whose optional fields
   are all absent is read back whole* stays green. Mutation: read the
   column with `CoverSource.valueOf(rs.getString("cover_source"))`, no
   null check.
9. **Tidy on green**, the gate run plainly, then the documents: the task
   line ticked, a `PROGRESS.md` entry, then the PR, its body naming the
   guards' mutations.

## Risks and decisions
**`CoverSource.of(label)`, on the enum.** The names handed out already live
on `CoverSource.label` (Tophe, T052), so reading one back is the enum's: the
request maps through `of` and keeps `null`, as D12 has an adapter do. The
match is exact, the name the lookup gave. *Rejected:* a `when` over the
three names in `NewBookRequest`, a second copy of the labels at the edge;
`CoverSource.valueOf` on the text, which reads `INVENTAIRE`, not the
contract's `inventaire.io`.

**Taken as null, never refused.** The contract says a name that is not a
source's, the house's own included, is taken as null; the empty string the
`minLength` excludes is such a name and is taken as null too, no `400` code
being declared for the field. *Rejected:* a validation error on
`coverSource`, which the contract does not describe.

**The source on `Edition`, stored as the enum's name.** S4 and S7 read the
choice from the stored edition, and D11 stores an enumeration as its
UPPER_SNAKE name read through `valueOf`; the column is nullable, so the
editions stored before it, and an add from the stand-in, have none, which
is S12's "no chosen source". *Rejected:* the label as the stored text,
which a renamed label would orphan; a table of its own, a child with no
list.

**The held edition is untouched by construction.** `EditionRepository` has
no `update`, and `AddBookToBookshelf` inserts an edition only when the
house lacks the ISBN, so the book's source never reaches a held edition;
step 6 guards it. *Rejected:* an update of the source on a held ISBN, which
the contract says is ignored.

**No default on the new parameters.** `NewBook`, `NewBook.of` and `Edition`
take `coverSource` explicitly, like `coverUrl`, so no construction forgets
it silently; the cost is one line in each file listed above.
