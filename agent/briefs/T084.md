## Risks and decisions
**The home page keeps the chosen default in the choice's state, without
asking `MeApi` again**; the card's add asks `MeApi` at each add already.
- Rejected: re-reading `currentReader()` — a request whose failure the
  spec does not describe.

**`ChooseDefaultState` holds the bookshelf asked and the default chosen
apart**: the spinner and message follow the tap, the mark the answer.
- Rejected: a union with one id — a failure after a success would put the
  mark back on the reader's first default.

**`BookshelfRow` takes `busy`, `locked` and `failed`**, booleans the view
sets per row, as `ReaderChoice` takes `adding` and `failed`.
- Rejected: one union prop — the tapped row is both busy and locked.

**The row reads its role to draw the star**, as it does for its word.
- Rejected: a domain function for one field compared — no rule to share.

**The message sits outside the link**, so the link's name stays the name
and role. **The default's star is `aria-hidden`**: *· par défaut* carries
the meaning, and S8 wants no button in that row.
