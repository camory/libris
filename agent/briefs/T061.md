## Goal
The lookup card shows the first candidate that has not failed, a dot per such
candidate, and the name of the shown cover's source. The reader can tap a dot
to see another cover. T062 then sends the shown cover's source on the add, and
T063 makes a held edition draw no dot.

## Risks and decisions
**The shown cover is the first candidate, in the answer's order, that has not
failed, unless the reader tapped another that has not failed.** S2's tests fire
every event on the one shown image. Tophe settled on 2026-10-06 that a
candidate keeps its dot while it loads. So nothing waits for a `load`: only a
failure changes the card, and the cover moves forward in the answer's order,
never back.
- Rejected: showing whichever candidate loads first in time. A later source
  would show, then give way to an earlier one, and S2's events on a hidden
  image could not be fired.
- Rejected: dots only for loaded candidates. Tophe ruled that out, and the
  scenario's dots would then depend on events the test never fires.

**One `img` per candidate, the shown one alone in the accessibility tree.**
The hidden images still load, so that their failure takes their dot away.
- Hide with the `hidden` attribute or `v-show`, which jsdom and Testing
  Library both read.
- A Tailwind `hidden` class does not work: no stylesheet is loaded in the
  specs, so `getByRole` would find three images and throw.
- No `loading="lazy"` on any of them: a hidden lazy image never loads.
- Rejected: one `img` whose `src` steps forward on error. A later candidate's
  failure would then go unseen, and its dot would stay forever.

**Exactly one element holds the source's name.** `queryByText` matches hidden
elements too. A name rendered per candidate and hidden would make the
scenario's `sourceName` find several.

**The state lives in the card.** The card already holds `coverFailed`, and no
other component reads the choice in T061. T062 needs the shown source at the
add and decides then how it leaves the card. U06's "props in, nothing out"
makes that T062's question, not this task's.
- Rejected: the view holding the choice now. That means an event out and a
  prop in for nothing T061 tests.

**Look, from the mockups.** The filled dot is a disc in `accent`; an unfilled
one is a 1.5 ring in `muted`. The name is `body`, centred under the dots, as
both artboards draw it. The new key is `isbn.card.coverSource`, beside
`isbn.card.cover`.
