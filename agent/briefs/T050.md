## Goal
`GET /api/v1/books` answers what it answers today, but a page reads fifty
ids and `next` from one keyset statement, then the editions and copies of
those fifty alone: its cost stops growing with the catalogue.

## Rules in play
- D12 — the page's ids and `next` come from a query port of `library.domain`,
  answering a read model built from one statement; no aggregate is rebuilt
  from it; editions and copies are read through their repositories.
- D02 — the port is a plain interface of `library.domain.copy`, implemented
  in `library.infrastructure.persistence` alone; the controller is untouched.
- D11 — order total, id last; an `after` no longer held continues after its
  place, one naming no edition answers an empty page and no next; fifty per
  page; migration `V005__…`, never edited once merged.
- D03 — the order is PostgreSQL's, through an ICU collation; no extension.
- D07 — order and page cases are JDBC slice cases; the use case is tested
  over fakes; `CatalogueScenarios` and `ApiContractTest` stay green, unedited.
- D10 — `invoke(readerId, after)` stays the only public member; the port
  keeps a verb (`findPage`); SQL keywords upper case; no visibility widens.
- D04 — the contract, its pin and the answer's shape are untouched.

## Risks and decisions
**The port lives in `library.domain.copy`, named `CatalogueEditions`.** D12
puts a query port in the asking context's domain, in its concern's
sub-package; the statement starts from the copies a reader's memberships let
them see (PRD §3, *that is their catalogue*) and answers ids, not a
projection, so no rule leaves an aggregate.
- `library.domain.catalogue`: the package Tophe's review of T043 removed.
- `CopyRepository.findPage`: a repository joins no other aggregate.

**The collation is applied in the statement, not on columns.** `COLLATE
ignoring_case_and_accents` on the text keys of `ORDER BY` and of the keyset
comparison; nondeterministic, so names equal but for case or accents tie and
the next key decides, as with the `Collator`.
- A column collation: it changes the `LOWER(name)` unique indexes and the
  PRD's name matching.
- A deterministic collation: its byte tie-break puts *Asterix 2* first.
- `unaccent` with `LOWER`: an extension the order does not need.

**The page size is the use case's, handed to the port.** `BrowseCatalogue`
keeps fifty; slice cases page by two; S2 proves fifty end to end.
- Fifty inside the adapter: fifty-one editions in every paging case.

**The page's copies come by edition, kept to the reader's bookshelves by
the use case**, as `LookupIsbnForReader` keeps the copies it shows.
- `findByBookshelfIds` kept: it reads the whole catalogue's copies.
- A finder by editions and bookshelves: a second list for a filter the use
  case already holds.

**Spaces and hyphens now count.** ICU at level 1 orders *One piece* before
*Onepiece*, which the `Collator` tied; nothing depends on it and the spec
asks for case and accents only. Named in the PR body and `GOTCHAS.md`.
