## Goal
A search whose words find nothing says so, quoting the query sent, in the
list's place; when Libris answers the nearest editions instead, the same
sentence stands over them and *Les plus proches :* labels their list. The
reader then knows the rows are not matches, and an empty answer no longer
looks like the whole catalogue.

## Risks and decisions
**The composable tells found, near and nothing apart, and keeps the query
it asked.** The sentence quotes the query as sent, which is the trimmed
text the composable asked, not the box's text, which the reader may have
changed since; and which of the three an answer is, is a reading of the
answer, application behaviour tested without a mount (D07). An answer with
no edition is `nothing` whatever its `near`, since the contract says such a
page is never near. `found` keeps its shape. Rejected: one `found` state
gaining `near` and `query`, the view branching on `books.length` (a rule
in the view); the view quoting `searchText` (not the query sent).

**The label is an `h2` and names the list.** As `HomeView`'s *Mes
bibliothèques*: the label in `text-label text-muted`, and the `ul` named
with `aria-label` from the same entry, as the frontend gotchas state for
a labelled list (`aria-labelledby` does not resolve in the specs). Step 7
reads the near rows through that name. Rejected: a `<p>` label with an
unnamed list (the label would name nothing for a screen reader).

**The guillemets follow U08 as written, with plain spaces inside.** U08
asks for the non-breaking space before `:`, `;` and `?` and guillemets for
quotes; it says nothing of the spaces inside guillemets, and the spec and
`docs/DESIGN.md` write them plain. A convention that outlives the task is
not the planner's, so the entry writes plain spaces, and the PR body
proposes to Tophe that U08 add the non-breaking space inside guillemets
(French typography, and on a narrow screen `».` could start a line).
Rejected: the non-breaking spaces now (a typography rule no document
states); blocking the task on it (U08 as written is followable).

**The sentence and the labelled block are two blocks.** The sentence
stands 20 above the label (U03, blocks 20 apart, as the switch and the
box are `mb-5`), the label 8 above the rows' block, as `HomeView`'s
`pb-2`. jsdom lays nothing out: the spacing is checked on the Pixel
against the mockups.
