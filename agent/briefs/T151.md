## Goal
On the add's tap, a box whose name holds text and whose roles are all
released is refused: it takes the `danger` outline whole, *Rôle manquant*
shows under it, nothing is sent, and when it is the first refused of the
form its roles' line takes the focus and comes into view. A box with an
empty name is never refused, so S9's drop stays silent.

## Risks and decisions
**A rule of its own, `authorRefusalsOf`, beside `refusalsOf`.**
`Refusals` maps each text field to one `Refusal`, and the form walks its
`fields` over it; the authors' refusals are one per box, so they come as a
list in the boxes' order, from a function the form asks on the same tap.
The empty-name exemption reads the name through the module's `text`, the
door T148's drop goes through, so a box never sent is never refused.
- Rejected: an `authors` member in `Refusals` (a second value type in a
  record every field caller reads); a refusal per box computed in
  `AuthorBox` (a rule in a component, and T152's rule spans boxes).

**The code is `missingRole`, its words `isbn.form.authors.refusal.*`.**
`missing` already names the title's refusal; the authors' words live
under `isbn.form.authors`, which `AuthorBox` translates itself.
- Rejected: `isbn.form.refusal.missingRole` (the box reaching into the
  fields' block).

**The box knows its refusal; the form knows the order.** `AuthorBox`
takes `refusal` and draws the outline and the message, as it draws its
word; the form keeps the last tap's answer per box, not per position, and
picks the first refused across fields and boxes. `focusRoles()` focuses
the roles' line and scrolls the bordered box to the centre, the form's
`{ block: "center" }` for a refused field; T152 focuses the name through
`focusName()`.
- Rejected: one `focusRefused()` reading the prop (the prop is not yet
  updated when `add()` calls it, so a `nextTick` in the form); the form
  scrolling the box itself (it reaches no element inside the box).

**The danger outline wins over `accent`.** The box's outline is a class
on a `div`: a plain `border-danger` loses to `focus-within:border-accent`
(frontend gotchas), so while refused the box takes neither `accent`
class, as `IsbnView`'s field drops `focus:border-accent` while refused.
No test sees it (D07 bars classes); checked by hand, as T145's `accent`.

**The message sits right under the box,** 8 under it, before the
suggestions and the roles' list when either shows: the mockup draws it
there, and the message belongs to the box, not to a list that comes and
goes.
- Rejected: the message after an open list (it would jump while the
  reader chooses).
