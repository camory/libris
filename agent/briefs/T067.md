## Test plan
All in `ApiContractTest`, run alone during the cycles (`./gradlew test
--tests fr.amory.libris.ApiContractTest`), its cases read from the XML
report, never from a piped log. `./gradlew detekt` before each commit; a
step is committed before its guard's mutation is checked.

1. **red then green — the unknown ISBN of `v0.9.0`.** Bump the pin's URL to
   `v0.9.0`. Red, measured: `404_UNKNOWN_ISBN` fails with `Status code does
   not match. Expected: 404, Actual: 403` (the use case's mock answers
   `null` to an ISBN no stub names); the other fifteen cases pass. Green:
   in `isbnLookupsAnswer`, the stub answering `noCopy(UnknownIsbn)` takes
   `isbnOf("9782000000013")` in place of `"9782000000006"`. One commit.
2. **guard — a bookshelf id that is not a uuid is a `Problem`.** The
   generated case `auto: path 'id' type mismatch`, new with `format: uuid`,
   passes with step 1's commit; no code of its own, no commit of its own.
   Mutation: drop `TypeMismatchException` from the `@ExceptionHandler` of
   `ProblemAdvice` (and its import); measured red, `Expected: 400|404,
   Actual: 403`, beside `auto: query 'after' type mismatch`. Revert; the
   PR body lists it.
3. **guard — the catalogue's cover address matches the contract.** The
   edition of `ASTERIX_1_HELD` holds a stored cover: its `coverName` is a
   well-formed `CoverName` (any 64 lower-case hexadecimal digits) in place
   of `null`. Green on arrival. Mutation: in `BookResponse.from`, build the
   address as `"/covers/${it.value}"`; measured red on `GET /api/v1/books
   -> 200 (application/json) (generated)`, `'coverUrl': Value '/covers/…'
   does not match pattern '^/api/v1/covers/[0-9a-f]{64}$'`. Revert; the
   commit body and the PR body name it.
4. **Tidy on green**, `./gradlew check` run plainly, then the documents:
   GOTCHAS as below, the task line ticked, a `PROGRESS.md` entry, the PR,
   its body naming both guards' mutations and the case count read from the
   XML report.

## Risks and decisions
**The old stub is replaced, not kept.** `v0.9.0` sends no request on
`9782000000006`, and a stub no scenario key fixes is the kind D07 removed
in T068. Rejected: keeping both stubs (a dead stub reads as a case).

**The stored cover is a fixed name, not a hashed picture.** The catalogue
copies the edition's `CoverName` into the address; the bytes behind it are
`FindCover`'s, which the catalogue never calls. Rejected: `coverOf(…).name`
over a recorded picture (hashes bytes the case never serves).

**The path id's guard mutates `ProblemAdvice`, not the controller.**
Measured by the planner: typing the add's `id` as `String` and converting
it with `UUID.fromString` in `BookshelfController` leaves the generated case
green, so it proves nothing about the conversion; the advice is what answers
the case. Rejected: a controller mutation (green, not a guard).

**Contracteer 4.1.1 reads OpenAPI 3.1.0.** Measured by the planner on
2026-10-03: the pin bump alone runs 16 cases, one red, step 1's; the cover
operation's `image/*: {}` keeps its generated `200`. If the gate shows
otherwise (a parse failure, a case missing), that is a Contracteer gap: stop
and report `blocked` with the output (D04), no workaround.
