field 330 `$a`, cleaned by one function of the adapter, `summaryOf`, so the
lookup's card carries *Mont Tombe*'s and *Le Larousse du Pain*'s summaries

## Risks and decisions
**Fit.** One run: one new function and its test class, one line of
mapping, one expectation changed, one un-skip. No migration, no contract,
no dependency.

**The cleaning in a file of its own, `BnfSummary.kt`, tested in
`BnfSummaryTest`.** A file of the adapter's package named after its
concern, as `SourceHttp.kt` is, and a test named after the code it
exercises (D07). `BnfRecord.kt` already holds seven functions, and
detekt's `TooManyFunctions` counts a file's private helpers against a
default threshold of eleven. Rejected: `summaryOf` in `BnfRecord.kt` and
its cases in `BnfRecordTest` (the cleaning's helpers would crowd the
file to the threshold); a `Summary` value type in `bibliography.domain`
(the cleaning undoes the BnF's format, which no other source shares, and
the domain refuses no summary).

**The entities decoded: `&amp;`, `&lt;`, `&gt;`, `&quot;`, `&apos;`,
`&nbsp;`, and every numeric reference, decimal `&#231;` and hexadecimal
`&#xE7;`; any other named entity stays as written.** Neither recording
carries an entity in its markup; these are what an HTML serializer writes
for the characters it must escape. Rejected: jsoup or `commons-text`'s
`unescapeHtml4` (a new dependency for one field, against "no extra
dependencies"); the whole HTML table by hand (two thousand names no
record has shown).

**The markup is dropped before its entities are decoded** (step 5), so an
escaped `<` the publisher wrote is kept as text and never swallows the
words after it. Whether this is the code's first order or a guard is the
implementer's; the PR says which.

**What a line break is**: `</p>` followed by `<p…>`, `<br>`, `<br/>`,
`<br />`, and the text's own `\n`; every other tag, `<p>` and `</p>`
alone included, is dropped with nothing in its place. A space is a space
or U+00A0; a run is two or more of them, mixed or not. A capital is a
`\p{Lu}` letter; the marks are `.`, `!`, `?` and `…` (U+2026), so in
`épi...•` only the last `.` gains a space.
