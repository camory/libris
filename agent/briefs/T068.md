## Goal
Every answer is built by its response type, the proxy's headers are read
by one class tested in plain JUnit, and no hand-written test calls a
controller, before T067 and on add fields and stubs to this layer.

## Rules in play
- D02 — `RemoteIdentity` lives in `shared.infrastructure.web` and depends on
  no context; each response type stays in the context and the file it is in
  today; `library.infrastructure.web` still reaches no class of
  `bibliography.infrastructure.web`
- D04 — the pin stays `v0.8.2`; no contract edit; `ApiContractTest` still
  runs 15 cases (`tests=` of its XML report after the gate)
- D06 — the headers are read in one class, now `RemoteIdentity`, and nothing
  else in `backend/src/main` names a `Remote-*` header; every identity holds
  `ROLE_READER`, a member of `libris-admin` also `ROLE_ADMIN`; the display
  name falls back to the username when absent or blank; a missing user, a
  missing or blank email still authenticates nobody
- D07 — a value is tested where it is computed, a value only copied into a
  response gets no test, no hand-written test calls a controller; the web
  slice keeps `SecurityConfigTest` (refusals, `X-Requested-With`, health)
  and `ProblemAdviceTest`, nothing else; `ApiContractTest`'s stubs match
  exactly what a scenario key fixes and answer the test's own values,
  every nullable field the contract constrains filled; no scenario test is
  edited; a case of two or more statements carries Given / When / Then
- D10 — each response class gains `from` on its companion, one per source
  type; a controller calls a use case, then `from`, and builds no response
  itself; no visibility widened; Kotlin layout kept by hand; members
  imported when their bare name is unambiguous
- D12 — `RemoteIdentity.of(request)` reads its values from what it is
  given, so it is the only door: the constructor is private, as on `Cover`,
  and `of` answers `null` for a request that names nobody

## Test plan
One step is one case is one commit; `./gradlew detekt` before each commit;
a step is committed before its guard's mutation is checked. A step marked
red that is green on arrival becomes a guard: its commit body names the
mutation that reds it, checked and reverted, and the PR body lists it.
Each `RemoteIdentityTest` case calls `RemoteIdentity.of` on a
`MockHttpServletRequest`; no Spring context.

## Risks and decisions
**D06 names the filter as the one class reading the headers.** The backlog
line moves the reading to a class of its own; the rule's substance holds
(one class reads them, nothing else sees one) and only its wording goes
stale. The PR body proposes the amendment: "read in one class,
`RemoteIdentity`, which the filter calls". *Rejected:* blocking, for a
wording Tophe's line already settles.

**`RemoteIdentity`, a private constructor and `of(request)`.** `of` decides
every value and answers `null` when the request names nobody, as `Cover`. *Rejected:* a data class, whose `copy` exposes the private
constructor (a Kotlin warning, an error here); a function `(String) ->
String?` in place of the request, an indirection `MockHttpServletRequest`
makes useless.

**The refusals stay proven by `SecurityConfigTest` alone**, as the line
says; the null branch of `of` gets guards 11 and 12. *Rejected:* the same
cases again in `RemoteIdentityTest`.

**`CurrentReaderResponse.from` takes the authorities**, a list a plain
test builds; the controller passes `authentication.authorities`.
*Rejected:* the `Authentication`, a token to build or mock.

**One `from` per source type.** `CopyResponse` comes from a lookup's or a
catalogue's `CopyOnBookshelf` and from an add's `Added`; `IsbnResponse` from
`Held` or `Found`. Overloads keep the call reading
`CopyResponse.from(added)`. *Rejected:* `IsbnResponse.from(IsbnLookup)`,
which would have to answer for the two results that are problems.

**The add's stub still matches the example's body.** The key
`201_ADD_ONE_PIECE_1` fixes the body, so the `NewBook` it gives is an
argument, matched exactly as D07 says; only answers become the test's own.
*Rejected:* `any()` on the book, a stub wider than the key.
