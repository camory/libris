## Goal

the components call it plainly and a spec that asserts the call spies on
it instead of defining it; `HomeView.spec.ts`'s one unmarked case gains its
markers. The next component that scrolls needs no optional call and no
spec its own definition.

## Risks and decisions
**The setup lives in `frontend/vitest.setup.ts`, in the app program.** It
mirrors `vitest.global-setup.ts`, the one Vitest file the tree has, and is
named after it; it touches `Element`, which only `tsconfig.app.json` types
(DOM library), whose `include` already holds a root file, `vitest.d.ts`.
Rejected: `tsconfig.node.json` (no DOM, and adding it puts browser globals
in the config files); a file under `src/` (beside production code, inside
the boundaries rules, where no layer fits; `src/fixture` holds the ports'
fakes a spec imports).

**The no-op sits on `Element.prototype`, where a browser declares the
method.** The scenario files define and delete theirs there too, so their
`afterEach` removes the setup's definition and their next `beforeEach`
puts one back; no other file is affected, each spec file getting its own
jsdom and its own setup run (measured green while planning). Rejected:
`HTMLElement.prototype` (a second definition below the scenarios' and a
browser's place).

**A case that asserts the call spies, the file's `afterEach` restores.**
`vi.spyOn(Element.prototype, "scrollIntoView")` keeps `mock.contexts` and
`toHaveBeenCalledExactlyOnceWith`, so each case's assertions stay as
written; `vi.restoreAllMocks()` puts the no-op back after each case, and
none of the three files holds another spy it would undo. Measured while
planning: `vue-tsc`, ESLint and the 404 cases of the three component specs,
the three scenario files and `src/ui/views` green. Rejected: keeping `Object.defineProperty` in the cases (the
specs keep defining it, what the line removes); `restoreMocks: true` in
the config (an option for three files).

**The title case takes `// When` and `// Then`, no `// Given`.** Nothing is
given but the mount, which is the act whose result is asserted; the tree
marks such a case with the two markers (`AuthorBox.spec.ts`' *holds the
author's name*, `ReaderChoice.spec.ts`' *offers a row per reader*). Rejected:
the mount as *Given* (it leaves an empty *When*).

**Commit types follow what each commit changes.** Steps 1 and 5 touch
tests and their wiring alone, `test(frontend)`; steps 2 to 4 change a
component, `refactor(frontend)`, as the PR title, `refactor(frontend): T188
the browser's missing scroll defined once` (62 characters).
